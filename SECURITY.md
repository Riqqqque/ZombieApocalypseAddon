# Security Policy

## Supported Versions

Security fixes are applied to the current release for each supported Minecraft and loader target:

- NeoForge 1.21.1
- NeoForge 1.20.1
- Forge 1.20.1

## Reporting A Vulnerability

Do not publish exploitable server details, access tokens, private logs, or player data in a normal issue.

Use [GitHub private vulnerability reporting](https://github.com/Riqqqque/ZombieApocalypseAddon/security/advisories/new). Include the affected version, impact, reproduction steps, and the smallest useful log or configuration sample.

Ordinary crashes, compatibility problems, and config questions should use the normal [issue forms](https://github.com/Riqqqque/ZombieApocalypseAddon/issues/new/choose).
