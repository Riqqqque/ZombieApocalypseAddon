# Support

Start with the [wiki](https://github.com/Riqqqque/ZombieApocalypseAddon/wiki) and [troubleshooting guide](https://github.com/Riqqqque/ZombieApocalypseAddon/wiki/Troubleshooting).

Use the repository issue forms when you still need help:

- [Config help](https://github.com/Riqqqque/ZombieApocalypseAddon/issues/new?template=config_help.yml)
- [Bug report](https://github.com/Riqqqque/ZombieApocalypseAddon/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/Riqqqque/ZombieApocalypseAddon/issues/new?template=feature_request.yml)

For technical problems, include:

- Minecraft version and loader
- Zombie Apocalypse Addon version
- dedicated server or singleplayer
- relevant config values
- complete mod list
- `logs/latest.log` from a session where the problem happened
- exact reproduction steps

Upload long logs as an attachment or use a paste service. Do not paste access tokens, server addresses, private player information, or other secrets.

Support is provided for current official builds from [Modrinth](https://modrinth.com/mod/apocolypseaddon/versions) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/zombieapocalypseaddon/files). Modified or redistributed jars cannot be diagnosed reliably.
